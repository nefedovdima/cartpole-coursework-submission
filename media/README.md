# Иллюстрации из сохранённых журналов

Все MP4 — готовое воспроизведение прежних записей. Динамика не пересчитывалась
при сборке этого репозитория. Угол 0 вниз, pi вверх; оси одинакового масштаба.
Физическая запись длится10 с; видео содержит251 кадр,25fps,10.04с с обоими концами.
Видео демонстрирует один указанный случай и не заменяет [таблицы всех seeds](../RESULTS.md).

| Видео | Исходный случай | Результат |
| --- | --- | --- |
| [Классика](classical_success.mp4) | main, bottom, filter-on | final hold7.82с |
| [SAC-on](sac_on_success.mp4) | main seed1, best50k, bottom, eval-on | final hold7.44с |
| [TQC-on](tqc_on_success.mp4) | main seed0, best80k, bottom, eval-on | final hold6.80с |
| [DDPG best/last](ddpg_failure_or_degradation.mp4) | confirmation warmup5000 seed5, validation_1000, eval-on | best90k:7.90с; last100k:0с |

В DDPG-видео маятник может быть близок к верху при проваленном удержании из-за
скорости тележки. Это иллюстрация различия углового и полного критерия.
[Manifest](manifest.json) сохраняет точное начальное состояние, seed/checkpoint,
SHA модели, исходного журнального файла и видео. Полные журналы в Git не включены.
Отдельного устойчивого результата robustness эти видео не показывают.
