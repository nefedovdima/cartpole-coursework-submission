# Управление перевёрнутым маятником методами обучения с подкреплением

**Нефедов Дмитрий Львович, НИУ ВШЭ, ПМИ, группа БПМИ-233.**
Научный руководитель: **Бондарев Андрей Олегович**.

Отчёт об исследовательском проекте. Маятник нужно поднять из нижнего
положения и удержать около верхней вертикали, не выпустив тележку за пределы
короткой направляющей. Задачу решают классический траекторный регулятор
и четыре метода обучения с подкреплением — все в общей симуляционной модели
и по общему протоколу. Отдельный защитный фильтр следит за тем, чтобы у тележки
оставался запас на торможение.

**[Отчёт PDF](docs/report/report.pdf) · [Видео экспериментов](docs/VIDEOS.md) ·
[Результаты](RESULTS.md) · [Запуск и воспроизведение](REPRODUCIBILITY.md)**

## Главный результат

SAC и TQC с фильтром решают исходную валидационную задачу во всех трёх
запусках обучения. DDPG успешен только на одном запуске из трёх, а SAC без
фильтра с базовыми настройками не решает задачу ни в одном из трёх запусков
основной серии — обе неудачи полностью приведены в таблицах, а не исключены
из них. О поведении SAC без фильтра при других настройках основная серия
не говорит; отдельно это проверялось на этапе подбора.

На 140 отобранных robustness-стартах включение фильтра увеличивает число
успехов с 441 до 796 из 980 исполнений и устраняет все измеренные превышения
желаемой границы тележки. При этом 184 исполнения из 980 доходят до конца
горизонта, так и не выполнив удержания: **безопасное движение тележки и решение
задачи — разные вещи, и здесь они измерены порознь.** Результат относится
к этому фиксированному набору стартов и не является доказательством общей
устойчивости.

Исследование целиком выполнено в симуляции. Обученные контроллеры на реальной
лабораторной установке не испытывались.

## Задача и модель

Вход модели — ускорение тележки `u`, а не сила:
`x'' = u`, `θ'' = (−g·sin θ − u·cos θ) / l`, где `g = 9,8` м/с², `l = 0,18` м.
Угол 0 направлен вниз, π — вверх. Интегратор Drake RK3, шаг управления 0,01 с,
точность 1e−6, горизонт эпизода 10 с.

Защитный фильтр корректирует запрос контроллера с учётом положения, скорости
и тормозного запаса. Желаемая граница ±0,24 м отличается от физического
события на ±0,25 м; рабочие пределы — `|u| ≤ 4` м/с² и `|v| ≤ 2` м/с. Фильтр
ограничивает движение тележки, но сам по себе маятник не поднимает и не держит.

Успехом считается полный горизонт плюс последние непрерывные 2 с в области
`|ошибка угла| ≤ 10°`, `|ω| ≤ 0,5` рад/с, `|x| ≤ 0,20` м, `|v| ≤ 0,20` м/с —
по записанным отсчётам.

## Результаты по сериям

**Основная серия.** Лучшие контрольные точки, оценка с включённым фильтром,
успехи из 20 валидационных состояний для seeds 0 / 1 / 2. Три именованных
сценария в отбор не входят и в таблицу не включены.

| Обучение | seed 0 | seed 1 | seed 2 |
|---|---:|---:|---:|
| SAC-on | 20/20 | 20/20 | 20/20 |
| TQC-on | 20/20 | 20/20 | 20/20 |
| DDPG-on | 20/20 | 0/20 | 0/20 |
| DQN-on | 20/20 | 14/20 | 20/20 |
| SAC-off | 0/20 | 0/20 | 0/20 |

Таблица основной серии в разделе 4.1 отчёта показывает те же обучения, но
оценённые в режиме их собственного обучения; для SAC-off оба режима дают
одинаковые нули.

**Подбор настроек и его проверка.** Вариант warmup5000 выиграл отбор Stage 1
для DDPG-on и SAC-off по закреплённому лексикографическому правилу, однако
минимальный успех по seeds 0/1/2 остался нулевым. На новых seeds 3/4/5
**обе конфигурации не прошли критерий подтверждения.** Все 33 обучения, включая
неудачные seeds, сохранены в компактных таблицах. Предположение о том, что
увеличенный начальный сбор опыта улучшает раннее посещение верхней области,
у SAC-off не подтвердилось. [Точные результаты и критерии](RESULTS.md).

**Структурированная проверка начальных условий.** Семь закреплённых
контроллеров (SAC и TQC, seeds 0–2, плюс классика), 140 общих стартов, семь
групп, два режима фильтра: 1960 эпизодов, образующих 980 пар.

| Метрика | off (980 эпизодов) | on (980 эпизодов) |
|---|---:|---:|
| Успешное финальное удержание | 441 (45,00 %) | 796 (81,22 %) |
| Превышение ±0,24 м с допуском | 585 (59,69 %) | 0 |
| Достижение горизонта | 446 | 980 |
| Горизонт достигнут, удержание неуспешно | 5 | 184 |

Это конечный development-набор, а не независимая итоговая оценка.
[Аудированные результаты](docs/ROBUSTNESS_RESULTS_DRAFT.md),
[таблицы и пять графиков](docs/assets/structured_robustness/README.md).

## Методы управления

| Метод | Роль в исследовании |
|---|---|
| Классика | Подъём по оптимизированной траектории, слежение и удержание LQR |
| SAC | Стохастическая политика с энтропийной регуляризацией; сравнение обучения с фильтром и без него |
| TQC | Развитие SAC с усечёнными квантильными оценками ценности |
| DDPG | Детерминированная политика; различия между seeds и деградация последних весов |
| DQN | Дискретный набор из девяти ускорений, обучение функции ценности действий |

В комплект входят **шесть выбранных main-best моделей SAC и TQC, seeds 0–2**.
Сохранённых весов DDPG и DQN здесь нет; их результаты и выбранный видеопример
DDPG включены как свидетельства прежних экспериментов.
[Шесть видео с постерами и пояснениями](docs/VIDEOS.md) показывают отдельные
сохранённые траектории, а не новые испытания и не вероятность успеха.

## Быстрый старт

Лёгкие проверки требуют только Python и не загружают модели, torch или Drake:

```bash
python3 -B -m scripts.reproduce_results --check
python3 -B -m scripts.reproduce_robustness --check
python3 -B -m scripts.verify_submission
python3 -B docs/report/scripts/check_report.py
```

Для тестов, графиков и inference проверено окружение Linux x86_64 / Python 3.12.3:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install --no-deps --no-build-isolation -e .
.venv/bin/python -m pip check
.venv/bin/python -B -m scripts.frozen_inference --load-check
```

Последняя команда только загружает шесть моделей и сверяет сохранённые пробы,
без шага среды. [Запуск политики, графики, обучение и raw-аудит](REPRODUCIBILITY.md)
разделены по требованиям и по фактически выполненным проверкам.

## Ограничения

Обучающих seeds мало, старты общие для контроллеров, валидационная область
узкая, а матрица стресс-тестов конечна. Аппаратной валидации нет, независимый
итоговый набор не создавался и не использовался.
[Полный список ограничений](docs/LIMITATIONS.md) ·
[Проверки комплекта](docs/CHECKS.md).
