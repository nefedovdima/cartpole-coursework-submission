# Математическая модель

Состояние интерфейса: `(x, v, theta, omega)`; SI: м, м/с, рад, рад/с.
Вектор Drake имеет порядок `(x, theta, v, omega)`. Угол `theta=0` направлен вниз,
`theta=pi` вверх. Команда `u` — ускорение тележки, м/с², а не сила или напряжение.

\[
\dot x=v,\qquad\dot v=u,\qquad\dot\theta=\omega,\qquad
\dot\omega=-\frac{u\cos\theta+g\sin\theta}{l}.
\]

Идеальная модель предполагает отслеживание заданного ускорения без задержки,
трения и насыщения исполнительного механизма сверх явного limiter. Масса не
входит в эту редуцированную модель. Свойства реального привода не идентифицированы.
`g=9.8`, `l=0.18`; [единая конфигурация](../cartpole/experiment_config.py).

| Величина | Рабочий предел | Аварийный предел |
| --- | ---: | ---: |
| Положение шарнира | 0.25 м | 0.27 м |
| Скорость тележки | 2 м/с | 2.5 м/с |
| Ускорение тележки | 4 м/с² | 5 м/с² |

Команда постоянна на интервале `dt=0.01` с. Общий `CartPoleEpisode` находит
первый выход из рабочей области по аналитическим `x(t)=x0+v0*t+u*t²/2`,
`v(t)=v0+u*t`, включая внутренний экстремум x. До времени события маятник
интегрирует исходный Drake: адаптивный RK3, accuracy=1e-6, maximum step=0.01,
fixed step выключен. Касание без выхода не завершает эпизод.
После terminal необходим reset. У отказа фильтра `dt_actual=0`, applied=None;
принудительная нулевая команда не подставляется.

## Фильтр

Желаемая граница `|x|<=0.24`; внутренний запас `L=0.239999` м,
`W=1.999999` м/с, `A=4` м/с². Из исходных binary64 x/v проверяется тормозной
запас и допустимость всего интервала при постоянной команде. Отфильтрованное
ускорение передаётся напрямую без промежуточного float32-преобразования.
Физическое событие position_limit остаётся на ±0.25 м.
Это проверяемое свойство идеальной тележки при оговорённых предпосылках;
глобальная безопасность численного Drake и успешный swing-up из K не доказаны.

## Наблюдения, действие и награда

Наблюдение нейросети: `[x/0.25, v/2, sin(theta), cos(theta), omega/sqrt(g/l)]` (float32).
Непрерывное действие нормировано на [-1,1], физический запрос `u=4*a`.
У DQN девять дискретных уровней от -4 до 4. В replay сохраняется запрошенное
действие (для DDPG после шума/clipping), исполненное действие измеряется отдельно.

При `q(z)=1/(1+z²)`, `h=(1-cos(theta))/2` награда R1-v0 равна

\[
r=\frac{dt_{actual}}{0.01}h\,q(x/0.25)q(v/2)q(\omega/2)q(u_{applied}/40)
-5\,\mathbb{1}_{terminated}.
\]

Состояние берётся в конце фактического перехода. Завершение по горизонту —
truncation с bootstrap; физический отказ — termination. Награда не заменяет
физический критерий успеха. Точные проверки: [RewardR1](../cartpole/rl/reward_pilot.py),
[контракт](../cartpole/rl/training_contract.py), [среда](../cartpole/rl/env.py).
