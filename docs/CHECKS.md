# Проверки submission

Контрольные суммы58 файлов источников исходного промежуточного отчёта совпали.
Из включённых compact CSV пересчитаны main best/last validation successes,
лексикографические ключи Stage1 и confirmation gate. Это отдельная проверка
агрегаций; полные raw серии повторно не аудировались.

Научные исходники перенесены побитово. Обучение, реальные rollout, серверные
операции и final-наборы при сборке не запускались. Проверка чистого клона,
окружения и PDF выполняется отдельно; результаты будут зафиксированы перед сдачей.
