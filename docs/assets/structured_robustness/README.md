# Компактные результаты structured robustness

Это development structured robustness **main**: 1960 эпизодов, 980 полных
пар off/on, 98 заданий, семь фиксированных контроллеров и семь групп стартов.
Timing40 не включён. Все шесть RL-политик обучались с фильтром; off/on здесь
обозначает режим исполнения одной политики, а не сравнение способов обучения.

Научная идентичность (`scientific_sha256`):
`c1cac3775426748520db67957e988fb7cf3706148d1cc515eca26e88118fb63b`.
Reporting commit: `6b458a9a93001366169012650467e3a2216d968e`.

## Состав и происхождение

Шесть CSV, `analysis_summary.json` и пять рисунков в PNG/SVG скопированы
побайтово из проверенного `reporting-candidate-r2`. Каждая копия сверена с
SHA исходного manifest до публикации и после копирования. Таблицы и рисунки
получены [воспроизводимым reporting-модулем](../../../cartpole/experiments/robustness_reporting.py).
Проверки находятся в [тестах](../../../tests/test_robustness_reporting.py).
[Черновик раздела](../../ROBUSTNESS_RESULTS_DRAFT.md) ссылается на этот пакет.

Новый [MANIFEST.json](MANIFEST.json) включает SHA всех файлов пакета, кроме
самого manifest, исходные SHA r2, reporting commit и область provenance.
Manifest является средством контроля целостности, **не цифровой подписью
подлинности**. `analysis_summary.json` сохранён без изменений: его описание
области хеширования и проверок относится к исходному reporting-экспорту r2;
для настоящего пакета действует новый manifest, включающий также этот README.

## Воспроизведение и внешний raw-аудит

Чтение таблиц, проверка их сумм и относительные ссылки работают без локального
каталога artifacts после включения пакета в Git. Пакет не содержит normalized
rows, raw trajectories, моделей или recovery. Он позволяет изучать готовые
агрегаты, но сам по себе не позволяет заново вывести их из эпизодов или
повторить полный raw-аудит.

Raw-аудит выполнен отдельно до reporting. Он пересчитывал метрики сохранённых
логов, не исполнял заново динамику и политики. При подготовке этого пакета
raw-аудит не повторялся. Воспроизведение из compact review и полный аудит
выполняются [robustness_analysis](../../../cartpole/experiments/robustness_analysis.py)
с [frozen protocol](../../../configs/robustness/manifest.json).
Необходимые внешние источники для полного main-аудита:

- `robustness-review-1789558151385076965.tar.gz`, SHA256
  `0c3b3685612f35da89332f8b36b165e96fd76d0056f12bf647a34e5d57f019e3`;
- `robustness-recovery-1789558163887525846.tar.gz`, SHA256
  `b2390e4f695ce45b2549423a2a591bf65e0ba0c5351771182e042bbb09496f18`.

Это сохранённые идентификаторы исходных архивов, не заявление об их повторном
полном чтении в данном этапе. Timing-архив не нужен для main и не объединяется
с ним. В существующем окружении команды из корня репозитория, после размещения
внешних архивов в текущем каталоге и с новыми выходными каталогами:

```bash
python -B -m cartpole.experiments.robustness_analysis \
  --review robustness-review-1789558151385076965.tar.gz \
  --archive-sha256 0c3b3685612f35da89332f8b36b165e96fd76d0056f12bf647a34e5d57f019e3 \
  --output normalized-main
python -B -m cartpole.experiments.robustness_reporting \
  --normalized normalized-main/normalized.json --output reporting-main-new
```

Для отдельного полного raw-аудита:

```bash
python -B -m cartpole.experiments.robustness_analysis \
  --review robustness-review-1789558151385076965.tar.gz \
  --archive-sha256 0c3b3685612f35da89332f8b36b165e96fd76d0056f12bf647a34e5d57f019e3 \
  --recovery robustness-recovery-1789558163887525846.tar.gz \
  --recovery-sha256 b2390e4f695ce45b2549423a2a591bf65e0ba0c5351771182e042bbb09496f18 \
  --verify-raw-metrics --check
```

Эти команды приведены для воспроизведения, на текущем этапе не запускались.
Численные агрегаты и детерминированные таблицы отделены от оформления графиков.
PNG/SVG могут побайтово отличаться между версиями Matplotlib и шрифтовыми
окружениями при совпадении таблиц. Версии Python и Matplotlib, использованные
именно при создании r2, его manifest не фиксирует; здесь они не угадываются
по текущему окружению. Это ограничение воспроизводимости оформления.

## Ограничения научной интерпретации

Это фиксированный development-дизайн, не независимый final test. Двадцать
состояний каждой группы общие для контроллеров; осевые и зеркальные точки
не образуют независимую выборку из всего пространства. Все старты допущены
фильтром. Общие доли имеют веса 3 SAC + 3 TQC + 1 классика и равные веса групп.
Для классики сохранено известное расхождение provenance (`known_mismatch`):
SAC-подобная specification при фактическом `CourseworkCartPole-v0` без
training contract; интерфейсы запросов классики и RL различаются.

Удержание проверено по отсчётам. Соблюдение желаемой границы тележки и успех
подъёма/удержания — разные метрики. Доли вмешательств — отношения сумм принятых
решений; для off они N/A. Большие corrections классики включают ограничение
амплитуды запроса. Агрегаты не доказывают механизм отдельных неудач, глобальную
устойчивость, безопасность всей динамики Drake или перенос на реальную установку.
