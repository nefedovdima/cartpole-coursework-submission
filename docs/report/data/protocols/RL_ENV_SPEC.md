# Среда: переносимое описание экспериментального контракта

x — м; v — м/с; theta — радианы, 0 вниз, pi вверх; omega — рад/с.
Команда u — ускорение тележки (м/с²). g=9.8, l=0.18 м.
Рабочие пределы |x|≤0.25, |v|≤2, |u|≤4; hard-пределы .27/2.5/5.
Drake RK3: accuracy=1e-6, maximum_step_size=.01, fixed_step=False.
Управление dt=.01 с, горизонт 10 с.
Исходный reset: независимый uniform lower-box
x,v∈[-.02,.02], theta,omega∈[-.05,.05]; training seed меняет поток, не границы.
Наблюдение использует периодическое представление угла.
Запрошенные действия, не исполненные после фильтра, сохраняются в replay.
Точный R1 и преобразования закреплены в
[reward](../../../../cartpole/rl/reward.py) и
[training_contract](../../../../cartpole/rl/training_contract.py),
[конфигурациях](../../../../configs/cloud/sac_training_v2_on.json).
Успех: полный горизонт и последние непрерывные 2 с: периодическая ошибка
относительно pi ≤10°, |omega|≤.5, |x|≤.20, |v|≤.20.
Критерий проверяется по отсчётам; отдельные интервалы не суммируются.
Validation содержит 20 фиксированных lower-box состояний; три named bottom/±.02
не входят в выбор. Final5000 здесь не создавался и не использовался.
