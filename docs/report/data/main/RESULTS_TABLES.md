# Полные таблицы внешних оценок

Источник: `evaluation_summary.csv/json` и `episodes.csv/jsonl`. Все числа пересчитаны по полным logs.
V — 20 validation; N — 3 named. Hold/return — средние по всем 23, включая неуспехи.
Lift2 — число эпизодов с первым непрерывным интервалом удержания ≥2 с; это строже краткого прохождения угла сверху.
X24 — эпизоды с интервалом |x|>0.24; X25 — события position_limit. F% — вмешательства / принятые решения.
В CSV отдельно есть строгие/разрешённые по допуску превышения, первый hold, longest hold, верх достигнут по углу, величина вмешательств и источник/SHA.
† Все данные TQC seed1 проверены, но внешнее задание не принято guard/очередью.
