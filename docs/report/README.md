[report.pdf](report.pdf) — 37 страниц, побайтовая копия редакции для 18.09.2026;
научный текст, LaTeX, рисунки и принятые видео не редактировались при переносе.
Исходник [report.tex](report.tex), главы [sections](sections/), [references.tex](references.tex).

```bash
python3 -B docs/report/scripts/check_report.py
# Сборка: только при установленном XeLaTeX либо Tectonic
bash scripts/build_report.sh
```

Сборка использует Times New Roman при наличии либо Liberation Serif; шрифты не
включены. Изменения TeX/шрифтов/движка могут менять вёрстку и SHA нового PDF.
В этой подготовке PDF не пересобирался. Историческая визуальная QA всех 37 страниц:
[снимок](../../provenance/report_source_qa.json), не новая визуальная проверка.

Data и media — необходимые копии для относительных ссылок LaTeX/PDF и автономной
передачи папки. SHA дубликатов проверены. Электронные ссылки могут блокироваться
политикой конкретного PDF-viewer; доступен [индекс приложений](../APPENDICES.md).

[SOURCE_MANIFEST](SOURCE_MANIFEST.json) сохранён без изменения как исторический.
В [PORTABILITY](PORTABILITY.json) явно объявлены семь производных Markdown-описаний
вместо документов с машинными путями. Изменены только проверки источников в двух
скриптах для учёта этих производных. CSV/JSON научного анализа, PDF, рисунки,
видео и текст отчёта не менялись. [Оригинальный delivery manifest](../../provenance/report_source_delivery.json).

`make_figures.py` пересоздаёт рисунки из включённых компактных данных; запускайте
его в отдельной копии этой папки, поскольку он пишет figures/.
Здесь проверено отдельное воспроизведение пяти канонических robustness-графиков;
пересборка всех рисунков отчёта не является выполненной проверкой этого переноса.
