# Промежуточный отчёт

[report.pdf](report.pdf) — редакция на 36 страницах к промежуточной сдаче
18.09.2026. Автор, группа БПМИ-233, руководитель и тема сохранены.
Редактируемые исходники: [report.tex](report.tex), [главы](sections/),
[библиография](references.tex).

```bash
python3 -B docs/report/scripts/check_report.py
# В отдельной копии комплекта, с установленным XeLaTeX либо Tectonic:
bash scripts/build_report.sh
```

Сборка использует Times New Roman при наличии, иначе Liberation Serif.
В проверенном окружении Times New Roman отсутствует; текущий PDF набран Liberation
Serif. Шрифты не включены в комплект. Другие версии движка/шрифтов могут менять
вёрстку и SHA. Исходные рисунки и данные сохраняются без изменений.

## Электронные материалы

В конце PDF размещена **одна ссылка** на главную страницу
[submission-репозитория](https://github.com/nefedovdima/cartpole-coursework-submission).
Репозиторий PRIVATE: необходимы авторизация и предоставленный владельцем доступ.
В PDF нет команд запуска локальных CSV/JSON/Markdown/MP4. Названия материалов
ведут читателя к разделам электронного приложения; подробные относительные ссылки
работают в [карте приложений](../APPENDICES.md) и [видеогалерее](../VIDEOS.md).
Библиографические и внутренние переходы PDF сохранены.

Адрес задан один раз в [appendix_links.tex](appendix_links.tex).
Первый аргумент команд eref/vref/applink сохраняет идентификатор файла для проверки
целостности исходников; в PDF выводится только его понятное название.
Проверка отвергает возвращение локальных ссылок, другой адрес репозитория,
дублирование ссылки и размещение её вне заключительного блока.

## Идентичность редакций

[SOURCE_MANIFEST](SOURCE_MANIFEST.json) — неизменённый исторический список
36 источников. [PORTABILITY](PORTABILITY.json) связывает семь переносимых
Markdown-описаний с оригиналами и раздельно хранит:

- historical_pdf — прежний PDF из commit e53d39699dacd0490d875df8d2ec7642503f3081;
- previous_editorial_pdf — проверенную локальную редакцию до подготовки публикации;
- current_pdf — текущий PDF и SHA его исходников.

Исторические [delivery](../../provenance/report_source_delivery.json) и
[QA](../../provenance/report_source_qa.json) относятся к прежней редакции на
37 страницах; их результаты не выдаются за проверку нового PDF.
Актуальный состав — [SHA256SUMS](../../provenance/SHA256SUMS).

Научные CSV/JSON, код, конфигурации, изображения, модели и шесть принятых видео
сохранены побайтово. Прежние дубликаты данных и media сохранены для совместимости
проверок происхождения; PDF больше не открывает их напрямую. Полные журналы
экспериментов не включены. make_figures.py требует отдельной рабочей копии:
он пишет в figures/. Графики и видео при публикации не пересоздавались.
