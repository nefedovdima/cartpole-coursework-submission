Большие исходные архивы и буферы опыта не входят в раздаточный комплект; шесть моделей SAC/TQC предназначены для исполнения и не заменяют данные для возобновления всех прежних обучений. Технические сведения о происхождении данных, прежних редакциях и проверках сохранены отдельно, чтобы они не затрудняли чтение научного текста.

Лабораторная модель и исходная классическая основа заимствованы с указанием источника. SAC, TQC, DDPG и DQN использованы в библиотечных реализациях. Происхождение заимствований и характер помощи при подготовке материалов раскрыты в документации репозитория. Видеопримеры показывают выбранные сохранённые траектории и не заменяют статистику серий. Для каждого ролика в репозитории указаны исходные эпизоды и правило отбора.
