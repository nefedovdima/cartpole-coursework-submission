# Видео экспериментов

[Главная страница](../README.md) · [Отчёт PDF](report/report.pdf) · [Результаты](../RESULTS.md)

Шесть принятых роликов построены из сохранённых симуляционных журналов.
Это не аппаратные испытания и не новые запуски моделей. Нажмите на постер
или ссылку MP4; если GitHub предлагает скачивание, откройте файл видеоплеером.
Удержание маятника и соблюдение границы тележки показаны раздельно.

Три контроллера с фильтром из общего nominal_00; один выбранный успешный старт.

## 2. DDPG: лучшие и последние веса

Confirmation warmup5000 seed 5: разные веса после 90 и 100 тысяч переходов. У last скорость тележки нарушает критерий удержания; близости угла к вертикали недостаточно.

[![DDPG: лучшие и последние веса](../media/posters/02_ddpg_best_vs_last.png)](../media/02_ddpg_best_vs_last.mp4)

## 3. Фильтр предотвращает остановку

[![Фильтр предотвращает остановку](../media/posters/03_filter_safety_rescue.png)](../media/03_filter_safety_rescue.mp4)
